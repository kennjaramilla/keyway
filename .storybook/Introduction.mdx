# Keyway UI

The component library for Keyway, built on Radix UI primitives and Tailwind CSS design tokens.

- Components live in `src/components/ui/<component>/` with a story and a test next to each one.
- Use the toolbar to switch between the light and dark themes.
- The Accessibility panel runs axe against every story.
